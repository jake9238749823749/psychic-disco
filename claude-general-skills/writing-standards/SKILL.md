# Writing Standards

Writing is finished when nothing can be removed, not when nothing can be added.

## Structure rules

- **Lead with the point.** The first sentence carries the conclusion or the ask. Background comes after, for those who need it.
- **One idea per paragraph.** If a paragraph needs "and also," split it.
- **Concrete beats abstract.** Replace claims with numbers, examples, or names. "Faster" → "cut load time from 4s to 1.2s."
- **The ask is explicit.** Every email/doc that wants something states exactly what, from whom, by when.

## Sentence rules

- Active voice by default. Passive only when the actor is unknown or irrelevant.
- Cut on sight: throat-clearing openers ("I hope this finds you well", "I wanted to reach out"), hedge stacks ("I think maybe we could possibly"), intensity padding ("very", "really", "incredibly"), and "in order to" (→ "to").
- Vary sentence length; keep the average short.

## Per-medium defaults

| Medium | Default |
|--------|---------|
| Email | ≤150 words, ask in first two lines, one topic |
| Document | TL;DR at top (3 bullets max), headings every ~300 words |
| Post/announcement | Hook in line one; no warm-up paragraph |
| Reply/comment | Answer first, reasoning second |

## Editing protocol (run in order on any draft)

1. **Structure pass** — right points, right order, right length? Cut whole sections before polishing sentences.
2. **Clarity pass** — would a smart stranger understand every sentence on first read?
3. **Cut pass** — remove 10% of words. There is always 10%.
4. **Verify pass** — names spelled right, numbers sourced, links work, dates correct.
5. **Tells pass** — for anything published or sent externally, sweep against `references/ai-tells.md` so the prose reads authored, not generated.

## Personalize this skill

Generic style rules produce competent prose; samples produce *the user's* prose. Add 2–3 examples of the user's best writing to `references/voice-samples.md`, then match their rhythm, formality, and vocabulary — read that file before drafting anything voice-sensitive.

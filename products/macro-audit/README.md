# The Macro Audit

Forget line-level checklists. This audit answers five structural questions about your agent operation.
Each one takes about ten minutes to assess. Together they tell you whether you have a system
or an expensive hobby.

**The five questions:**
1. **Leverage** — does the system multiply you, or employ you?
2. **Blast radius** — what's the worst one bad run can do?
3. **Verification** — does your confidence rest on evidence or on the builder's word?
4. **Unit economics** — does it get cheaper or more expensive as it grows?
5. **Compounding** — is month six automatically better than month one?

**How to run it:** read `01-the-five-dimensions.md`, score each dimension 1–5 with the maturity
scale in `02-maturity-scale.md`, write it up in `03-macro-report-template.md`. Fifty minutes,
one document, the truth about your operation.

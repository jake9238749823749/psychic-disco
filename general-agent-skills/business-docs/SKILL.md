# Business Documents

Every business document exists to cause a decision or transfer status. Identify which before writing a word.

## Universal rules

- **Lead with the point** — the rule lives in `writing-standards` ("Lead with the point (BLUF)"). This skill owns document structure, not prose rules; one home per rule.
- **Numbers over adjectives.** "Significant growth" → "up 34% QoQ." Every number has a source or is labeled *estimate*.
- **One ask per document.** Two asks compete; the reader picks neither.
- **Length caps are real**: status ≤ 1 page, one-pager = literally one page, exec summary ≤ 5 sentences.

## Status update format

```
TL;DR: <one sentence — on track / at risk / blocked, and the headline>

Wins: <2–3 bullets, each with a number where possible>
Risks: <what might go wrong, each with the ask that would defuse it>
Next: <2–3 items, each with owner and date>
```

## Proposal format

```
Problem: <one paragraph, with the cost of doing nothing>
Recommendation: <the pick, stated plainly>
Cost: <money, time, people>
Alternatives considered: <2–3, one line each on why not>
Decision needed by: <date, and from whom>
```

## Quality bar before sending

- A skimmer reading only bold text and the first lines gets the full message.
- Every claim a skeptical reader would challenge has a number or source attached.
- The recipient knows exactly what to do after reading, in one action or less.

## Gotchas

<!-- Seeded patterns — not yet observed in the wild. skill-maintenance replaces these with real incidents as they occur. -->

- A status update with three asks gets zero decisions. Readers triage multiple asks by effort and pick none — "one ask per document" is triage mechanics, not a style preference.
- A proposal that buries cost below the recommendation gets approved, then re-litigated. Cost discovered after the yes reads as a trap; put cost in the same visual block as the recommendation.
- An exec summary over five sentences gets forwarded, not read. Forwarded-but-unread is worse than unread — the sender assumes an alignment that doesn't exist. If it doesn't fit in five, the recommendation isn't crisp.

## Division of labor

This skill owns *structure* — format, order, what goes where. For line-level prose quality (cutting filler, active voice, the AI-tells sweep), run `writing-standards` after the structure is right. Structure first, polish second.

# Spec Playback — confirm before building

Fill this in from the elicitation, show it, and get a yes before writing anything.

```
Here's what I'll build — confirm before I start:

GOAL: <one sentence — the outcome and who it's for>
DONE WHEN:
  - <checkable criterion 1>
  - <checkable criterion 2>
CONSTRAINTS: <stack / format / time / budget that must hold>
NOT DOING (this round): <explicit exclusions that cut scope>
APPROACH: <the chosen option, one line — if there was a choice to make>

Good to go?
```

Keep it to what fits on a phone screen. If the playback is longer than the answers that produced it, you're over-specifying — cut it back.
